# Мини-система денежных переводов на Go.
 ## Проект представляет собой систему денежных переводов между пользователями с использованием структур, методов, интерфейсов и механизмов многозадачности.
 ### Проект разделён на 4 части, каждая в своей ветке:
 - **Часть 1: Cоздание пользователей и выполнение простых транзакций.
 - **Часть 2: Добавление транзакций и обработка нескольких пользователей.
 - **Часть 3: Обработка транзакций с горутинами.
 - **Часть 4: Реализация конкурентного доступа.
## Как запустить проект?
1. Склонировать проект:
```bash
git clone https://github.com/Mugnis/-GuessNumber.git
```
2. Скачайте зависимости:
```bash
go mod tidy
```
3. Запустите игру:
```bash
go run main.go
```
## Архитектура проекта:
- `main()` — точка входа, инициализирует пользователей, наполняет очередь транзакций, запускает пул воркеров и распределяет задачи по каналам.
- `Worker()` — функция фонового воркера, которая в цикле конкурентно вычитывает транзакции из канала и передает их на обработку.
- `ProcessingTransactions()` — метод платежной системы, координирует логику перевода: ищет пользователей в мапе по ID, инициирует списание и зачисление средств.
- `Withdraw()` — метод пользователя, проверяет баланс и списывает сумму под защитой мьютекса.
- `Deposit()` — метод пользователя, зачисляет сумму на баланс под защитой мьютекса.
- `AddUser()` — метод для добавления нового пользователя в общую мапу системы.
- `AddTransaction()` — метод для добавления новой транзакции в слайс-очередь.
## Используемые технологии:
- **Язык программирования:** Go 1.27.1 и выше).
- **Стандартная библиотека:** `sync` (пакеты `sync.Mutex` и `sync.WaitGroup` для безопасной многопоточности), `errors`, `fmt`.
